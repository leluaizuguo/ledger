# V2 — 资产管理 & 预算 实现计划

> V1 基础上叠加，不重写

**新增能力：** 多账户 / 转账 / 预算 / 趋势图 / 搜索 / CSV 导出

## 数据模型变更

```
Bill 新增字段: accountId (string)
新增 Account 表: { id, name, type, balance, icon, createdAt }
新增 Budget 表: { id, month, categoryId?, amount }  // categoryId=null 表示总预算
```

## 改动清单

1. **DB 迁移** — Dexie v2 schema: bills 加 accountId 索引, accounts 表, budgets 表
2. **默认账户** — 现金/储蓄卡/信用卡/支付宝/微信
3. **AccountPage** — 新 Tab "资产"，账户列表 + 余额
4. **记账页修改** — 选择账户（默认现金）
5. **转账** — 账户间转账（A扣钱 B加钱，一条记录）
6. **预算设置** — 月度总预算 + 分类预算，存入 budgets 表
7. **预算进度条** — 图表页顶部显示预算使用情况
8. **趋势折线图** — 近6月支出/收入趋势
9. **账单搜索** — 账单页加搜索框
10. **CSV 导出** — 补充 CSV 格式导出

## 页面结构调整

底部 Tab 从 3 个变 4 个：
```
记账 | 账单 | 图表 | 资产
```
