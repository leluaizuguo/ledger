# V3 — 智能功能 实现计划

## 本次实现

1. **模板记账** — 保存常用账单为模板，记账时一键套用
2. **周期入账** — 设置固定周期的自动账单（工资/房租/订阅），每月自动提醒
3. **消费分期** — 大额消费标记分期，每月自动生成分期账单
4. **报销标记** — 记账时标记待报销，账单页筛选查看

## 数据变更

```
新增 Template 表: { id, name, amount, type, categoryId, accountId, note }
新增 Recurring 表: { id, name, amount, type, categoryId, accountId, dayOfMonth, active }
Bill 新增字段: isReimbursable(boolean), reimbursed(boolean)
Bill 新增字段: installmentId(number?) — 关联分期
新增 Installment 表: { id, billId, totalAmount, periods, periodAmount, startMonth, note }
```
