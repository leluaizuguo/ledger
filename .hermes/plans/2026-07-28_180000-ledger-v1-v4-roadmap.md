## 〇、应用形式：PWA vs App

| 维度 | PWA | 原生 App (React Native / Flutter) |
|------|-----|------|
| 开发成本 | 一套代码全平台 | iOS + Android 双端 |
| 分发 | 免审核，URL 即安装 | App Store 审核 |
| 离线 | Service Worker 缓存 | 原生离线 |
| 系统能力 | 受限（推送 / 后台 / 文件） | 完整 |
| iCloud/云同步 | 不可用 | 原生可用 |
| 小组件 | 不可用 | 原生可用 |
| 快捷指令 | 不可用 | 原生可用 |
| 指纹/FaceID | WebAuthn (有限) | 原生生物识别 |
| 更新 | 即时 | 审核等待 |
| 用户安装心理门槛 | 低（点链接） | 高（App Store 下载） |

**推荐：PWA 起步，后续可包壳上架**

理由：
- V1/V2 阶段功能纯 Web 即可覆盖（CRUD + 图表 + 本地存储）
- 智能记账的"截图识别"PWA 也能做（`<input type=file capture>` + OCR API）
- 如果用户验证了产品价值，后期用 Tauri/Capacitor 包壳上架即可
- 乐先生是 Windows 开发者，Web 技术栈开发效率最高

## 技术栈（PWA 路线）

| 层 | 选择 | 理由 |
|----|------|------|
| 前端框架 | React + TypeScript | 生态丰富，乐先生熟悉 |
| 样式 | Tailwind CSS | 快速出 UI |
| 状态管理 | Zustand | 轻量，适合中等复杂度 |
| 路由 | React Router | SPA 标配 |
| 本地存储 | IndexedDB (Dexie.js) | 比 localStorage 能存更多，支持索引查询 |
| 图表 | Recharts | React 原生，饼图/折线图/柱状图 |
| 构建 | Vite | 快 |
| PWA | vite-plugin-pwa | Service Worker + manifest 一键生成 |
| 测试 | Vitest + React Testing Library | |
| OCR（V3） | Tesseract.js | 浏览器端 OCR，截图识别账单 |

## 分层规划

### V1 — 核心记账（MVP）

**目标：** 能记、能查、能分类，数据不丢

```
功能清单：
├── 记账
│   ├── 记一笔（金额 + 分类 + 备注 + 时间）
│   ├── 支出 / 收入切换
│   └── 快速金额输入（计算器式键盘）
├── 分类管理
│   ├── 预设分类（餐饮/交通/购物/娱乐/住房/医疗/教育/其他）
│   ├── 二级分类（如 餐饮→早餐/午餐/晚餐/外卖）
│   └── 自定义增减分类
├── 账单列表
│   ├── 按时间倒序
│   ├── 按月份筛选
│   └── 按分类筛选
├── 月度概览
│   ├── 当月总支出 / 总收入 / 结余
│   └── 分类支出占比（饼图）
└── 数据持久化
    ├── IndexedDB 本地存储
    ├── JSON 导出
    └── JSON 导入（备份恢复）
```

**交付物：** 一个可用的 PWA，安装到手机/桌面，日常记账无压力

---

### V2 — 资产管理 & 预算

**目标：** 不止记账，能看清钱在哪、花超了没

```
功能清单：
├── 多账户
│   ├── 现金 / 储蓄卡 / 信用卡 / 支付宝 / 微信
│   ├── 账户余额
│   └── 账户间转账
├── 预算管理
│   ├── 月度总预算
│   ├── 分类预算
│   └── 预算进度条 + 超支提醒
├── 增强图表
│   ├── 月度支出趋势（折线图）
│   ├── 分类月度对比
│   └── 净资产变化
├── 账单搜索
│   ├── 关键词搜索
│   ├── 金额范围筛选
│   └── 日期范围筛选
└── 数据导出增强
    └── CSV 导出（Excel 可打开）
```

---

### V3 — 智能功能

**目标：** 减少手动输入，自动化重复记账

```
功能清单：
├── 模板记账
│   ├── 保存常用账单为模板
│   └── 一键套用模板
├── 周期入账
│   ├── 固定周期自动生成账单（工资/房租/订阅）
│   └── 通知提醒确认
├── 截图识别（核心智能功能）
│   ├── 上传支付宝/微信账单截图
│   ├── Tesseract.js OCR 提取金额
│   └── 自动填充记账表单 → 人工确认
├── 消费分期
│   ├── 大额消费标记分期
│   └── 每月自动生成分期账单
└── 报销标记
    └── 标记待报销 + 报销状态管理
```
