# 记账 使用说明 v0.6.5

## 快速开始

1. 打开 https://leluaizuguo.github.io/ledger/ （建议 Edge 浏览器）
2. 手机 Chrome/Edge → 右上角菜单 → **添加到主屏幕** → 桌面出现"记账"图标
3. 打开即用，数据存本地，不需要注册

---

## 记账

### 手动记账
- 点底部 **✏️ 记账** → 选支出/收入 → 点数字键盘输入金额 → 记一笔
- 选账户（💵现金/🏦储蓄卡/💳信用卡/🔵支付宝/🟢微信）
- 点分类 emoji → 可加备注 → 确认

### 语音记账
- 点底部 🎤 → 对着手机说话 → 自动识别金额和分类
- 支持连续多笔："坐车10元吃饭25元" → 自动拆成两条
- 支持口语："三块五" → ¥3.50
- Edge 浏览器直连，无需代理

### 摇一摇记账
- 点顶部 📳 按钮开启 → 支付完晃一下手机 → 自动触发语音记账

### 快捷链接
其他 App/快捷指令可通过链接直接记账：
```
https://leluaizuguo.github.io/ledger/#/record?amount=25&note=午餐
```

### 组合付款
记账时勾选"组合付款" → 选第二个账户和金额 → 一笔消费拆两个账户

### 拍照/定位/报销
记账时可点击 📷拍照、📍定位、勾选待报销

---

## 账单

- **📋 账单**：按月查看，搜索备注，点击月份切换
- **导出**：JSON（备份恢复）/ CSV（Excel 打开）
- **导入**：JSON 文件恢复数据
- **文本导入**：粘贴"午餐25元\n地铁6块"批量导入
- **批量模式**：点"批量"→勾选多条→一键删除
- **长按账单**：弹出退款/删除/取消

---

- 月度预算进度条（点击设置）

## 日历

- 月视图日历，每天显示当日支出/收入金额
- 左右箭头切换月份

## 资产

- **账户**：查看/修改各账户余额，总资产展示
- **周期**：添加固定周期账单（房租/工资等，每月自动记账）
- **模板**：保存常用账单模板，记账时可一键套用
- **分期**：对大额消费创建分期计划
- **存钱**：设置存钱目标，打卡存入

## 常见问题

**Q: 数据会丢吗？**
A: 数据存浏览器 IndexedDB 中，清浏览器数据会丢失。请定期导出 JSON 备份。

**Q: 换手机怎么办？**
A: 账单页 → JSON 导出 → 新手机打开 → 导入 JSON。

**Q: 语音识别不工作？**
A: 用 Edge 浏览器。Chrome 需要代理才能用语音。

**Q: 图标是黄色的？**
A: 临时占位图标，后续更新。
