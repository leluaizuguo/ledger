# 记账 使用说明 v0.12.1

## 快速开始

1. 打开 https://leluaizuguo.github.io/ledger/ （建议 Edge 浏览器）
2. 手机 Chrome/Edge → 右上角菜单 → **添加到主屏幕** → 桌面出现"记账"图标
3. 打开即用，默认本地模式，数据存浏览器 IndexedDB，不需要注册
4. PWA 自动更新：部署新版本后浏览器自动检测并更新 SW，无需手动刷新

---

## 本地模式（默认）

不登录即可使用全部基础功能，数据存在当前设备。

### 手动记账
- 点底部 **✏️ 记账** → 选支出/收入 → 点数字键盘输入金额 → 记一笔
- 选账户（💵现金/🏦储蓄卡/💳信用卡/🔵支付宝/🟢微信）
- 点分类 emoji → 可加备注 → 确认

### 语音记账
- 点底部 🎤 → 对着手机说话 → 自动识别金额和分类
- 支持连续多笔："坐车10元吃饭25元" → 自动拆成两条
- 支持口语："三块五" → ¥3.50
- Edge 浏览器直连，无需代理

### 摇一摇记账
- 点顶部 📳 按钮开启 → 支付完晃一下手机 → 自动触发语音记账

### 快捷链接
其他 App/快捷指令可通过链接直接记账：
```
https://leluaizuguo.github.io/ledger/#/record?amount=25&note=午餐
```

### 组合付款
记账时勾选"组合付款" → 选第二个账户和金额 → 一笔消费拆两个账户

### 拍照/定位/报销
记账时可点击 📷拍照、📍定位、勾选待报销

## 账单

- **📋 账单**：按月查看，搜索备注，点击月份切换
- **排序**：所有账单按日期整体排序，自己和他人的账单混排，同一天内按录入时间排序
- **导出**：JSON（备份恢复）/ CSV（Excel 打开）
- **导入**：JSON 文件恢复数据
- **文本导入**：粘贴"午餐25元\n地铁6块"批量导入
- **批量模式**：点"批量"→勾选多条→一键删除
- **长按账单**：弹出修改/删除/取消
- **修改账单**：长按 → 修改 → 可改金额、类型、分类、账户、备注、日期，保存后自动更新账户余额并同步

## 多设备同步（可选）

点击顶部「**登录同步**」→ 注册/登录 → 自动开启多设备同步。

### 功能
- 多设备数据自动推送/拉取（3秒间隔，全量同步）
- **同步更快**：一次请求同时完成上传和下载（原来要跑三趟），网络不好时等待时间大约降到三分之一
- **圈子隔离**：注册时填邀请码加入已有圈子，留空自动创建新圈子
- **加入/退出圈子**：顶部圈子栏可退出当前圈子，或用邀请码加入别的圈子。退出后自己的账单保留，只是不再与他人共享
- 圈子内所有成员看到同一本账，按日期整体排序
- **离线也能看**：同步成功过一次后，圈子成员的账单会缓存到本机。之后没网、服务器关了也照样能看到全部账单
- **状态提示**：顶部圆点显示 在线（绿）/ 同步中（黄闪）/ 离线（橙）/ 失败（红）
- 资产 → 同步 tab 可配置服务器地址
- **修改同步**：长按账单修改后自动同步到服务器，所有设备可见
- 同步竞态保护：记账过程中新增的账单不会被误删

### 启动同步服务器
在 PC 上双击 `D:\ledger\server\start.bat`，等待出现 `Sync URL: https://ledger.lelihome.vip`。
在 App 的「资产 → 同步」tab 填入 `https://ledger.lelihome.vip` 并保存即可。

## 常见问题

**Q: 数据会丢吗？**
A: 本地模式数据存浏览器 IndexedDB。清浏览器数据会丢失，定期导出 JSON 备份。登录同步后数据存在服务器。

**Q: 换手机怎么办？**
A: 未登录：账单页 → JSON 导出 → 新手机导入 JSON。已登录：新手机登录同一账号自动同步。

**Q: 语音识别不工作？**
A: 用 Edge 浏览器。Chrome 需要代理才能用语音。

**Q: PWA 不更新？**
A: 每次部署新版本 SW 会自动更新（含唯一时间戳）。如果长时间未更新，手机端清除站点数据后重开即可。

**Q: 没网 / 服务器关机能用吗？**
A: 能。自己的账单本来就存在本机；圈子成员的账单在成功同步过一次后会缓存到本机，断网、服务器宕机都能照常查看。恢复联网后自动补同步。

**Q: 同步服务器怎么搭？**
A: PC 上装 Python 3.11+，`cd D:\ledger\server && .venv\Scripts\pip install -r requirements.txt`，然后双击 `start.bat`。
